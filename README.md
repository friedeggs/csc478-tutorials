# CSC478 Tutorials

## Tutorial 2 — Probability Theory and Estimation (`2026-09-17-probability.ipynb`)

Companion notebook to Lecture 2. Interactive demos (sliders) of random variables,
joint/marginal/conditional densities, expectation, Bayes' rule, linear regression
with PyTorch, and RANSAC. All figures are also written as vector PDFs to `figures/`.

### Setup (about 2 minutes)

Requires Python 3.10 or newer (`python3 --version`). From this folder:

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab 2026-09-17-probability.ipynb
```

Then **Run ▸ Run All Cells**. The notebook is self-contained: no extra files or data downloads.

Notes:

- PyTorch is only used on the CPU. On Linux, install the small CPU build to skip the
  CUDA download: `pip install torch --index-url https://download.pytorch.org/whl/cpu`.
- If you use conda instead of `venv`: `conda create -n csc478 python=3.12 && conda activate csc478`,
  then `pip install -r requirements.txt`.
- Sliders need the Jupyter widget extension, which ships with `ipywidgets>=8` and JupyterLab 4;
  if a slider shows as text, restart JupyterLab after installing.
- To export a static copy: `jupyter nbconvert --to html 2026-09-17-probability.ipynb`
  (`--to webpdf` also works after `pip install "nbconvert[webpdf]"`). Widgets do not survive
  export, so the final "Static figures" section re-renders every demo at its default settings.

## Tutorial 4 — HoG Object Detection (`2026-10-01-hog_demo.py`)

Companion to Lecture 4 (slides 44–48: IoU, average precision, sliding windows, HoG).
An "I spy" game: find every **3** among ~100 rotated, scaled, overlapping MNIST digits,
first by hand while looking only at the histogram of oriented gradients (HoG) under a
magnifier, then with a sliding-window detector you write.

### Run

Same setup as above (`pip install -r requirements.txt`; this tutorial needs only numpy and pygame), then:

```bash
python hog_detector.py
```

```bash
python 2026-10-01-hog_demo.py
```

The first command runs the self-tests of your exercises; the second opens the demo. Leave
the demo running while you code: it reloads `hog_detector.py` every time you save it.

### What to do

All your code goes in `hog_detector.py`. Each exercise is a small function with a docstring
that says exactly what to return; `python hog_detector.py` checks it.

| # | Function | Slides | What |
|---|---|---|---|
| E1 | `image_gradients` | 48 | gradient magnitude and angle per pixel |
| E2 | `orientation_votes` | 48 | magnitude-weighted votes into orientation bins |
| E3 | `hog_descriptor` | 48 | cell histograms, stacked and normalized |
| E4 | `iou` | 44 | intersection over union of boxes |
| E5 | `nms` | 47 | non-maximum suppression |
| E6 | `detect` | 47, 95 | sliding window over a pyramid of scales and rotations |

1. **Manual** (after E1–E3): the scene starts hidden. Move the magnifier and compare the
   live HoG with the reference HoG of the training 3s; click where you think a 3 is. The mode
   bar counts the 3s left and your misses. Rotate and resize the magnifier (Q / E, mouse
   wheel) and try other HoGs (keys 1–5, B C U O) to cope with rotated digits. V reveals the
   train scene. The **blind test** scene is never revealed.
2. **Scan** (after E4–E6): Space runs your `detect`. Boxes are green when they hit a 3
   (IoU > 0.5) and red otherwise; the mode bar shows TP / FP / FN, precision, recall and AP.
   Edit `DetectConfig` (scales, angles, stride, thresholds) to experiment.
3. **Train**: Space trains a linear SVM (given, numpy) on windows from the train scene; Scan
   then scores with it (M switches between template and SVM). Compare the two on the blind test.
4. N makes a new random test scene that you *can* reveal, to look at your detector's mistakes.

Answers are released during the tutorial. After `git pull`, any exercise you have not written
uses the released answer automatically (its chip in the demo turns blue); write your own to
replace it. `python 2026-10-01-hog_demo.py --no-answers` ignores released answers.
